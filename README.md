# ABG Values & Oxygen Delivery – Quick Reference

A sage-green, single-page quick reference for:

- **Normal ABG values** – pH, PaCO₂, HCO₃⁻, PaO₂, SaO₂, base excess (with ROME reminder)
- **Oxygen delivery devices** – nasal cannula, simple mask, partial rebreather, non-rebreather, Venturi mask: liter flow, FiO₂, low vs. high flow, humidification, and whether FiO₂ changes with the patient's RR/VT

Everything lives in `index.html` — no build step or dependencies. It works on phones, desktops, and prints cleanly.

## View it online with GitHub Pages

1. Upload `index.html` and `README.md` to a GitHub repository.
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, set **Source** to *Deploy from a branch*, choose `main` and `/ (root)`, then **Save**.
4. After a minute, the page will be live at `https://<your-username>.github.io/<repo-name>/`.

> Ranges vary slightly between textbooks and facilities — follow your program's and facility's references.
